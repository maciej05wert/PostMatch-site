Accessibility Statement

Last updated: May 2026

Our Commitment

PostMatch is committed to ensuring digital accessibility for all users. We are continually working to improve the accessibility of both the PostMatch website and the PostMatch desktop application.

Website Accessibility

The PostMatch website aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA. These guidelines explain how to make web content more accessible to people with disabilities. Conformance with these guidelines helps make the web more user-friendly for everyone.

Measures taken on this website include:

  • Skip navigation link to bypass repeated content
  • Semantic HTML landmarks for screen reader navigation
  • All images include descriptive alternative text
  • Interactive elements are keyboard accessible
  • Focus indicators are visible for keyboard navigation
  • Colour contrast ratios meet WCAG AA standards
  • Respects the prefers-reduced-motion media query
  • ARIA roles and labels applied to interactive components

Desktop Application

The PostMatch desktop application is a Windows application built with a web-based interface. We are working to improve its accessibility and welcome feedback on specific issues encountered.

Known Limitations

We are aware of the following limitations and are working to address them:

  • Some data visualisations in the desktop application do not yet have full screen reader descriptions
  • The desktop application does not currently support high contrast Windows themes

Feedback and Contact

We welcome feedback on the accessibility of PostMatch. If you experience any barriers or have suggestions for improvement, please let us know through our GitHub repository. We aim to respond to accessibility feedback within 5 business days.

Technical Specifications

The PostMatch website relies on the following technologies for conformance with WCAG 2.1:

  • HTML5
  • CSS3
  • JavaScript

Assessment Approach

PostMatch assesses accessibility through self-evaluation. We review our content and code against WCAG 2.1 Level AA success criteria during development.

Formal Complaints

If you are not satisfied with our response to an accessibility issue, you may contact the relevant enforcement body in your region. In the United Kingdom this is the Equality and Human Rights Commission.
